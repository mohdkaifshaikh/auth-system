# Authentication system project:

A production-grade authentication system built with Node.js, TypeScript, and PostgreSQL.

## Goals

- Learn production backend architecture
- Build secure authentication
- Explore JWT, OAuth2, RBAC, Sessions, Passkeys
- Follow industry best practices

## Tech Stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- pnpm
